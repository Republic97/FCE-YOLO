# FCE-YOLO

Official implementation of **FCE-YOLO: A Method for Tomato Leaf Pest and Disease Detection in Natural Scenes**.

This repository provides the source code and configuration files for the proposed FCE-YOLO method.

## Main Components

- Feature Pyramid Shared Convolution (FPSC)
- Cross-level Dual-branch Enhancement Fusion (CDEF)
- EMASlideLoss

## Code

The complete project files are provided in `FCE-YOLO.zip`.

Please refer to the README included in the project package for detailed environment, training, validation, and usage instructions.

## Data

The original image dataset is not publicly redistributed due to copyright and redistribution restrictions.
